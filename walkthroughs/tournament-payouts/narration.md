# Tournament Payouts & Manager Cut — Narration Script

Pronunciation guide for the voice model: say **"FLI" as "Fly"** and **"FliHub" as "Fly Hub"**.

This script is written to match the recorded beats in `tournament-payouts.beats.json`. Each numbered line corresponds to one beat; the assembly step aligns the generated audio to those timestamps.

---

1. **In FliHub, an admin opens the payout testing dashboard for the season.**

2. **The season summary shows the total prize pool, and how it is split between pros, managers, and franchises.**

3. **Seeding the first tournament produces the finishing order and calculates every placement's payout.**

4. **Expanding the tournament reveals the team standings and a math check against the prize pool.**

5. **Each pro row lists the gross payout, the manager's percentage cut, and the resulting net amount.**

6. **The summary confirms the tournament total matches the configured payout rules.**

7. **The demonstration resets the seeded tournament, leaving the demo data clean.**

---

## Notes

- This narration describes only behavior the application actually demonstrates on screen.
- No real payments are triggered; the page uses synthetic standings and payouts.
- Manager percentages shown are the configured demo values (for example 10%–15%).
